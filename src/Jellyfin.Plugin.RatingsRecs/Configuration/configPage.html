Ratings & Recommendations

Dependencies / Dipendenze

      Thumbs in the web client need File Transformation / I pollici nel client web richiedono File Transformation.

      Add the repository https://www.iamparadox.dev/jellyfin/plugins/manifest.json (Dashboard → Plugins → Repositories), install File Transformation from the catalog and restart Jellyfin. See its README.

      Aggiungi il repository qui sopra (Pannello di controllo → Plugin → Repository), installa File Transformation dal catalogo e riavvia Jellyfin.

      Alternative / In alternativa: paste this tag in Dashboard → General → Custom HTML (branding) or in JavaScript Injector / incolla questo tag nel codice HTML personalizzato o in JavaScript Injector:

      <script defer src="/RatingsRecs/Web/ratings.js"></script>

      If Jellyfin runs under a base URL, prefix it (e.g. /jellyfin/RatingsRecs/Web/ratings.js). After any change reload the web page with Ctrl+F5 / dopo ogni modifica ricarica la pagina con Ctrl+F5.

      Ratings / Voti

      Ratings are never deleted when the mode changes / I voti non si cancellano cambiando modalità.

      Engine / Motore

      Changes apply at the next computation (Recompute now, or within 6 hours) / Le modifiche valgono dal prossimo calcolo (Ricalcola ora, o entro 6 ore).
